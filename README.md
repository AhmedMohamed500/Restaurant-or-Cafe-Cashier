# RestaurantFlow POS

نظام عربي احترافي لإدارة دورة تشغيل المطاعم والكافيهات، يبدأ من وحدات القياس وينتهي بفاتورة الكاشير. التطبيق يعمل محليًا بالكامل داخل المتصفح ولا يحتاج إلى قاعدة بيانات خارجية أو اشتراك مدفوع.

## ما تم تنفيذه

- وحدات القياس وعائلات الوزن والحجم والعدد.
- دليل المواد بثلاث مراحل: خام، تحت التشغيل، ومنتج تام.
- مخازن مستقلة لكل مرحلة مع أرصدة وقيمة دفترية.
- وصفات ديناميكية ومكونات ونسب هالك وتكلفة تلقائية.
- أوامر تصنيع ذرّية: تحقق من الرصيد، خصم المدخلات، إضافة الناتج، وحساب التكلفة الفعلية.
- سجل حركات مخزون غير قابل للتعديل المباشر.
- تحليل تكلفة وهامش ربح.
- شاشة كاشير لمسية بطرق دفع وخصم تلقائي لمكونات الوصفة.
- نسخ احتياطي JSON وإعادة تحميل البيانات التجريبية.
- تخزين دائم عبر IndexedDB وDexie.

## التشغيل

```bash
npm install
npm run dev
```

ثم افتح العنوان المحلي الذي يظهر في الطرفية.

## الفحص

```bash
npm run typecheck
npm run lint
npm run test
npm run build
```

## بيانات التجربة

التطبيق يبدأ تلقائيًا بفرع الزمالك، وثلاثة مخازن، ووحدات قياس، ومواد خام، وتجهيزات، ومنتجات نهائية، ووصفات بيتزا واقعية بأسعار تجريبية بالجنيه المصري. البيانات وهمية ومخصصة للتجربة.

## قواعد البيانات

لا يستخدم المشروع Supabase أو Firebase أو أي API خارجي. طبقة التخزين موجودة في `src/db`، ومنطق المخزون والتصنيع معزول في `src/domain` لتسهيل استبدال IndexedDB لاحقًا.
